டிராக்டர் வாடகை கணக்கு App – வாடிக்கையாளர் பாக்கி வசதியுடன்

செயல்பாடுகள்:
- வாடிக்கையாளர் பெயர், தொலைபேசி, இடம், வேலை வகை
- மணி/ஏக்கர் அளவு × வாடகை விகிதம் = மொத்த வாடகை
- பெற்ற தொகை மற்றும் பாக்கி கணக்கு
- வாடிக்கையாளர் வாரியாக மொத்த வாடகை, பெற்ற தொகை, பாக்கி
- வாடிக்கையாளரிடமிருந்து புதிய பணம் பெறும்போது, பழைய பாக்கி வேலைகளுக்கு முதலில் தானாக ஒதுக்கீடு
- டீசல், டிரைவர் கூலி, பழுதுபார்ப்பு, சர்வீஸ், உதிரிபாகம், கடன் தவணை, காப்பீடு உள்ளிட்ட செலவுகள்
- தினசரி / மாதாந்திர / வருடாந்திர / மொத்த சுருக்கம்
- பதிவுகளைத் திருத்துதல், நீக்குதல்
- தரவு சாதனத்தில் உள்ளூராக சேமிக்கப்படும்

Android APK:
  flutter pub get
  flutter build apk --release
APK: build/app/outputs/flutter-apk/app-release.apk

Windows EXE:
Windows கணினியில்:
  flutter config --enable-windows-desktop
  flutter create --platforms=windows .
  flutter pub get
  flutter build windows --release
EXE: build/windows/x64/runner/Release/

குறிப்பு:
Flutter SDK தேவை. Android மற்றும் Windows தரவுகள் தனித்தனியாக சேமிக்கப்படும்; cloud sync இல்லை.
புதிய பணம் பெறும் பதிவு, வாடிக்கையாளரின் பழைய பாக்கி வேலைகளுக்கு தேதி வரிசையில் ஒதுக்கப்படும்.
முக்கிய கணக்குகளுக்கு சாதன backup வைத்திருக்கவும்.
