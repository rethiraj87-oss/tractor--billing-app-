மொபைலில் APK உருவாக்குவது – தமிழ் வழிகாட்டி

தேவையானவை:
- Android மொபைல்
- இணைய இணைப்பு
- Chrome browser
- GitHub இலவச கணக்கு

முக்கியம்:
இந்த ZIP-ல் Flutter source code மற்றும் GitHub Actions build workflow உள்ளது.
GitHub cloud-ல் APK build செய்யப்படும். ZIP-ஐ மட்டும் திறந்தால் APK ஆகாது.

படிகள்:
1. Chrome-ல் https://github.com/signup சென்று இலவச கணக்கு உருவாக்கவும் / உள்நுழையவும்.
2. New repository உருவாக்கவும். பெயர்: tractor-rental-accounts
   README, .gitignore, license auto-add செய்ய வேண்டாம்.
3. இந்த ZIP-ஐ மொபைலில் extract செய்யவும்.
4. Extract ஆன folder-இல் pubspec.yaml, lib/main.dart, README_TAMIL.txt மற்றும் .github/workflows/build-apk.yml ஆகியவற்றை GitHub repository-க்கு upload செய்யவும். Folder structure அப்படியே இருக்க வேண்டும்:
   pubspec.yaml
   README_TAMIL.txt
   lib/main.dart
   .github/workflows/build-apk.yml
5. GitHub-ல் Actions tab திறந்து "Build Tractor Accounts APK" workflow தேர்வு செய்து Run workflow அழுத்தவும். முதல் முறையில் GitHub Actions-ஐ enable செய்ய ஒப்புதல் கேட்கலாம்.
6. Build வெற்றியடைந்ததும் Actions-ல் அந்த run-ஐ திறந்து Artifacts பகுதியில் tractor-accounts-apk ZIP-ஐ download செய்யவும்.
7. Download ஆன artifact ZIP-ஐ extract செய்து app-release.apk-ஐ திறந்து Install செய்யவும். Android அனுமதி கேட்டால் அந்த browser/file manager-க்கு மட்டும் "Install unknown apps" அனுமதி வழங்கவும்.

கவனிக்க:
- GitHub Actions-ல் இலவச பயன்பாட்டு வரம்புகள்/கணக்கு கட்டுப்பாடுகள் இருக்கலாம்.
- Build log-ல் பிழை வந்தால் screenshot அனுப்பவும்.
- இந்த workflow Android APK மட்டும் உருவாக்கும்; Windows EXE-க்கு தனி workflow தேவை.
- App தரவு போனில் உள்ளூராக சேமிக்கப்படும். App uninstall செய்தால் தரவு அழியலாம். வேறு சாதனத்துடன் auto sync இல்லை.
